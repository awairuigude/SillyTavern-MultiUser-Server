简单配置

  1. 顶部的插头图标配置 API，选择聊天补全，填好接口地址、API Key 和模型。只需要填一次，每次刷新后点连接就好。
  2. 顶部的小人齿轮 → 用户设置 → 角色广场，可以直接导入已有的角色卡，也可以自行导入。
  3. 每次选择或切换角色卡后，聊天之前，务必到顶部的书本图标「世界书」，选中角色卡对应的世界书。
  4. 用户设置 → UI 主题，里面内置了部分主题，也可以修改页面宽度、字体大小等。默认 Dark Lite，页面宽度 60。
  5. 右边的笑脸图标可以创建人设，可以引导 AI 描写的方向。
  6. 最右边的卡片图标可以选择、切换、添加角色卡。
  7. 最左边的按钮调整预设。设定好的预设可以不用调，不小心改了，可以切换别的再切换回来。模型没有输出时，可以尝试开启流式传输，再重新连接。
  8. 下面的剑仙RE-Neo是默认预设面板，比较通用。潮汐预设工具里面有各种 AI 的预设，可以根据调用的 API 模型自行切换。
  9. 下方魔法棒图标里的柏宝书默认跟随上面的 API 配置进行自动总结，可以随时查看、修改剧情，推荐一直开启。
